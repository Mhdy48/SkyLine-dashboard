# ✈️ SkyLine | Airline Dashboard

SkyLine is a modern and responsive airline dashboard designed with a clean and minimal interface.
The project focuses on creating a smooth user experience with interactive elements, responsive layouts, and a simple dashboard structure.

### ✨ Features

* Responsive dashboard layout
* Dark / Light mode
* Interactive revenue chart
* Animated statistics
* Smooth page transitions
* Custom Tailwind CSS styling

### 🛠️ Built With

**HTML5 • Tailwind CSS • JavaScript • Chart.js • Font Awesome**

---

A front-end project built to practice modern UI development, responsive design, and interactive dashboard components.
